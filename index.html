COA Architecture Reference & Viva Insights

3-Address Architecture

Format: OP Dest, Src1, Src2

Employs 3 address fields per instruction. Destination and two sources are distinct. Requires fewer total instructions to evaluate expressions but instructions need more bits to encode registers.

2-Address Architecture

Format: OP Dest, Src (Dest = Dest OP Src)

One operand serves both as a source and the destination of the result. Requires a MOV instruction to preserve or initialize variables, striking a balance between instruction length and count.

1-Address Architecture

Format: OP Operand (Implicit Accumulator)

Uses a dedicated hardware register called the Accumulator (AC). All arithmetic operations are performed between AC and memory. Subexpressions must be stored in temporary memory locations (STORE T1).

0-Address Architecture

Format: OP (Implicit Stack Top)

Stack-based architecture (e.g. Burroughs B5000, JVM). Operands are implicitly popped from the Top of Stack (TOS) and the result is pushed back. Naturally evaluates postfix (Reverse Polish) notation with no memory addresses in arithmetic opcodes.
